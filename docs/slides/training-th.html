หลักสูตรฉบับลงลึก — เติมช่องว่าง 8 จุดที่คอร์สทั่วไปข้าม

15 โมดูล · 128 บท · 17 แล็บ · ~42 ชั่วโมง

ปัญหาที่หลักสูตรนี้ตั้งใจแก้

คอร์สทั่วไปสอนให้ “ใช้ agent เป็น” ซึ่งพอสำหรับคนเดียว แต่ไม่พอเมื่อทีมทั้งทีมใช้พร้อมกันและของขึ้นโปรดักชัน

  • ปรับ prompt ด้วยความรู้สึก เพราะไม่มีเครื่องวัด
  • ต้นทุนบานโดยไม่รู้ว่าเงินไปไหน
  • ทำงานได้เฉพาะกับโปรเจกต์ใหม่ ไม่ใช่โค้ดจริงที่มีอยู่
  • เปิดสิทธิ์กว้างเพราะรำคาญ แล้วกลายเป็นช่องโหว่

ช่องว่าง 8 จุด

แต่ละจุดเพิ่มเพราะถ้าไม่มี เวิร์กโฟลว์จะพังตอนขยาย — เรียงตามความเสียหายถ้าข้าม

G1 · M12 · 9 บท

Evals — วัดผลระบบ agent ของตัวเอง

ถ้าวัดไม่ได้ คุณกำลังปรับ prompt ด้วยความรู้สึก LLM มี variance สูงพอที่ "ลองแล้วรู้สึกว่าดีขึ้น" จะเป็นสัญญาณรบกวนล้วน ๆ

G2 · M13 · 9 บท

Security และ Threat Model ของ agent

coding agent มีโมเดลภัยคุกคามที่ต่างจาก web app โดยสิ้นเชิง และ skill ที่ติดตั้งคือโค้ดที่รันด้วยสิทธิ์ของคุณ

G3 · M02 · 9 บท

Context Engineering

ทักษะที่แยกคนที่ใช้ agent เป็นกับไม่เป็นชัดที่สุด และให้ผลตอบแทนสูงกว่าการเปลี่ยนโมเดล

G4 · M08 · 7 บท

Brownfield และ Legacy

แล็บที่เริ่มจากโฟลเดอร์ว่างสอนงานที่แทบไม่มีใครทำจริง งานจริงคือ codebase อายุ 6 ปีที่ไม่มีเทสต์
